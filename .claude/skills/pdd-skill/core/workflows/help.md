# Help

## Purpose

Explain the available PDD workflows, when to use them, and the usual order.

## Use When

- The user wants a quick reference.
- They ask what PDD can do.
- They need help choosing the right workflow.

## Inputs

- optional workflow name if the user wants targeted help

## Produces

- quick-start guidance
- workflow routing help
- per-workflow explanation when requested

## Default Next Step

Route the user into the best matching workflow rather than leaving them with abstract guidance only.
