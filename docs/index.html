The Crew

Five specialists. Zero god agents.

Each crew member has one job in the voyage pipeline — and every action they take is logged, checkpointed, and observable. No freestyle.

🗺️ Sea Chart board

Voyages flow left-to-right through pipeline columns. Cards show live status, per-phase build state, and progress. Terminal voyages collapse into Completed & Failed.

🕸️ Crew Map graph

Pause, resume, inject context, redirect a phase, or cancel — every intervention triggers a Vivre Card checkpoint so no work is ever lost. Try the buttons during the demo.

The Dial System

Every role dials its own model

A provider-agnostic LLM gateway: per-role provider/model mapping, sliding-window rate limiting, and automatic failover chains — with a Vivre Card checkpoint before every switch.

Crew roleActive provider · modelFallback chain
⚓ captain anthropic claude-sonnet-4 anthropic→openai→ollama
🧭 navigator claude_code sonnet anthropic
🩺 doctor ollama llama3 none
🔨 shipwright openai gpt-4o ollama
⚙️ helmsman claude_code claude-sonnet-4 anthropic

Configured per-voyage via PUT /api/v1/voyages/{id}/dial-config — JSONB role mapping, no restart needed. Providers: anthropic, openai, ollama, claude_code (runs your local Claude Code CLI — subscription auth, no key stored).

Failover, live

Rate limiter trips (100k tokens / 100 req per 60s window) → Vivre Card checkpoint → switch to the next provider in the chain → provider_switched event on the Den Den Mushi.

Below Deck

The machinery of the voyage

Everything an agent does is evented, checkpointed, sandboxed, and committed to real git history.

🐌 Den Den Mushi Redis Streams

Typed inter-agent events with consumer groups, dead-letter stream, and replay-from-offset. Per-voyage stream grandline:events:{voyage_id}.

voyage_plan_createdtests_passedprovider_switched+17 more

🃏 Vivre Cards PostgreSQL JSONB

Agent state snapshots at every stage, iteration, pause, and failover. Restore, diff two checkpoints, or clean up old ones — resumable voyages, no work lost.

checkpointrestorediffcleanup

📦 Execution Service gVisor sandbox

All agent code runs in isolated containers — per-user sandboxes, resource limits, path-traversal guards, auto-recreate on death. Never on the host.

ExecutionBackend ABCswappable

🌿 Git Integration real repos

Each agent works on its own branch — agent/{crew}/{voyage} — with commits, pushes, PR creation, and conflict detection. Host allowlist prevents token exfiltration.

🔐 Auth default-deny

JWT with refresh rotation; every route closed unless explicitly allowed. WebSocket auth rides the grandline-bearer subprotocol — no tokens in URLs.

Cancel voyage?
